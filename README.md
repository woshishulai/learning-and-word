# 词境 · 在故事里学英语

基于 uni-app Vue 3 的首篇可交互学习版本。使用项目已有《少年与英语》文章及九张配图，包含三个情节、18 个重点词、六道理解题、36 道词汇练习，以及词库和间隔复习。当前不是 3500 词完整课程。

## 本机体验

```sh
npm install
npm run dev:h5
```

打开 http://127.0.0.1:5173/ 。点击“开始学习”，依次体验阅读、点词、理解题、词卡、原句选择、新语境填空和结果页。每次操作成功后保存进度；刷新后点击“继续学习”恢复。已经完成的情节也可以从首页学习路线重新开始。

默认是本机模式，页脚明确显示“本机体验 · 自动保存”。浏览器与设备之间不共享进度。浏览器验收产生的首节学习记录可能保留在测试浏览器内，不影响其他浏览器或用户。关闭终端后开发服务器会停止。

## 学习规则

- 三个情节依次开放，每段 6 个重点词。
- 阅读点击释义仅记录“已接触”；理解题不冒充词汇掌握。
- 原句选择用于找回语境；新句填空检查目标词的独立回忆。大小写、首尾空格和句尾标点不影响答案，词形仍须正确。
- 首次新语境答对：约一天后复习。答错或跳过：十分钟后复习。
- 到期复习连续答对，间隔逐步变为 3、7、14、30 天；三次到期复习答对后显示“较稳定”。这是可调的首版产品规则，不是效果承诺。
- 自由练习与薄弱词加练不提前提升等级，也不推迟已安排的复习。
- 同时只保留一个未完成任务；切换到另一任务前有提示，已完成课程和单词记录保留。
- H5 朗读使用设备提供的浏览器语音合成；没有假音频。小程序暂不显示朗读入口，尚未配置真人音频或 TTS 云服务。

## uniCloud 云函数

**已于 2026-10-14 部署到支付宝云 `learning-and-word`（`env-00jy6y1rc1sw`）。** 在线试用：https://env-00jy6y1rc1sw-static.normal.cloudstatic.cn/ 。真实云端已验证创建学习身份、开始阅读、收藏单词、刷新恢复及 CSV 下载。

1. 用 HBuilderX 打开项目，将 `uniCloud-alipay` 关联到你的支付宝云服务空间。
2. 上传 `uniCloud-alipay/database/learning-students.schema.json` 和 `learning-articles.schema.json` 的数据库 Schema。
3. 执行 `npm run build:cloud`，然后上传部署 `uniCloud-alipay/cloudfunctions/learning-api`。
4. 使用 HBuilderX 编译 / 发行 Web 或 App，编译器会注入绑定空间配置。`config/learning.js` 仅在注入空间与指定支付宝云 ID 匹配时启用云模式。普通 `npm run dev:h5` 未注入配置时仍为本机模式。不要手填服务空间密钥到源码。
5. 用两个独立浏览器分别学习，确认彼此隔离、刷新续学、断网时显示未保存、恢复网络后能重试。

云端模式自动创建独立的匿名学习身份，以随机 token 验证；服务端只保存 token 的哈希。身份保存在当前设备，**还不是手机号/微信账户，也不提供跨设备登录或身份找回**。本机旧进度不会自动导入云端，二者存储隔离。

所有云端操作经过云函数；客户端不直接读写数据库。服务端从身份凭证决定文档归属，按课程内容判题，使用服务端时间安排复习，并通过版本条件更新阻止重复提交和并发覆盖。发生版本冲突时，页面提示刷新进度。

接口：

| action | 请求 | 返回 |
| --- | --- | --- |
| create | 无 | 新身份凭证、初始学习状态 |
| read | studentId、token | 该身份的学习状态 |
| dispatch | studentId、token、revision、event | 服务端验证并更新后的状态 |

`server/learning-api.js` 为维护源文件。部署目录的 `index.js` 由打包脚本生成，不要单独修改。课程或规则变动后，重新执行 `npm run build:cloud` 并部署。

参考：[uniCloud 云函数](https://uniapp.dcloud.io/uniCloud/cf-functions)、[数据库 Schema 权限](https://doc.dcloud.net.cn/uniCloud/schema.html)。

### 导入文章题库（2026-10-14）
文章可选 questions 数组。可直接参考 examples/primary-with-questions.json（2 段小学原文、3 题）。保持原有 id/title/level/paragraphs/words 字段；每批最多 50 篇，每篇最多 200 题。已有文章 id 不覆盖，新版内容使用新文章 id。

题目字段：
- id：本篇唯一，小写字母开头，只含小写字母、数字和连字符。
- type：choice（选择）或 fill（填空）。
- scope：paragraph（段落题）、article（全文理解）、word（词汇运用）。
- paragraph：仅段落题必填，从 1 开始，必须对应原文段落。
- word：仅词汇题必填，必须对应本篇 words 中的 term。
- prompt / promptZh：题干 / 中文翻译。填空用 ___；中文翻译也应保留空格，避免直接显示答案。
- options / optionTranslations：选择题选项 / 对应翻译，2 至 6 个选项。
- answer：标准答案；选择题填写选项原文，不填 A/B。
- acceptedAnswers：填空题允许的其他答案，可选，最多 10 项。大小写、两端空格和句尾标点自动归一化。
- explanation：必填解析，提交后展示。

学习顺序：完整阅读 → 每段原文及其段落题 → 全文理解题 → 词汇题 → 结果及错题重练。未配置题目的环节自动跳过。旧文章没有 questions 仍可使用。
进度按用户与文章保存于 articleProgress，退出/刷新后恢复；题目判分使用云端保存的题库，不接受客户端答案键。学习期间允许辅助，结果不计入独立掌握等级。错题重练仅覆盖错题的最新结果，不重做已答对题。
管理员在 learning-api 配置至少 32 字符的 ARTICLE_IMPORT_TOKEN，书架“文章导入”填写相同密钥。示例仅用于本机验证，未发布到公共书架。
验证：31 项测试通过（含导入校验、恢复、重复提交、服务端判分、错题重练、旧格式兼容）。本机浏览器完成示例导入和全流程验证。

### 段落回看与练习模式

- 学习页可选择任意原文段落，或直接看第一段；返回当前学习时保留题目和未提交答案，不修改完成进度。
